CSS Grid Changes How We Build Pages

By Staff Reporter

Developers are moving away from floats and positioning hacks. With a few lines of Grid, an entire page layout can be described in rows and columns, then rearranged for any screen size.

The newspaper layout below places a wide headline across all three columns, with stories flowing in a left rail, a centre column and a right rail.

In Brief

  • Flexbox for components, Grid for pages.
  • Named grid areas make CSS readable.
  • Responsive layouts need fewer media queries.

Why Named Areas Matter

Using grid-template-areas, the layout reads like a sketch of the page. Moving a block is as simple as editing one string.

The centre column is the widest, which keeps the main reading line comfortable while side columns carry supporting content.

Weather

Sunny with a high chance of clean code.

Quote of the Day

“Layout is just rows and columns.”

Opinion: Stop Fighting the Layout

When a page has both rows and columns, reach for Grid first. It removes wrappers, spacing hacks and fragile widths.
